# Release notes

## 0.1.1 — Directory submission candidate

- Provide an independent plugin repository and a standalone `sictec-deftpdf`
  marketplace, without the private application or its Git history.
- Connect the existing DeftPDF OAuth MCP service and guide setup, original
  private uploads, compression, OCR, Word conversion, ordered merge and split.
- Explain account-bound input expiry, durable replay, result downloads, existing
  entitlements, subprocessors and unsupported local-byte/attachment transfer.
- Preserve the existing seven remote schemas and account/processing behavior.

A submission candidate is not an approved or publicly listed directory release.
